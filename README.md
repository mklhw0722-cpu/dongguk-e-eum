# 동국e음 (Dongguk e-eum)

동국대학교 교육학과 재학생·졸업생·교수진을 연결하는 교육학과 전용 종합 소통 플랫폼입니다.

동국e음은 **정보의 통합, 경험의 공유, 구성원 간 연결**이라는 세 가지 가치를 바탕으로 개발되고 있습니다.

학교·학과 정보를 한곳에서 확인하고, 선후배의 학업·진로 경험을 공유하며, 졸업 이후에도 학과 구성원들이 지속적으로 교류할 수 있는 공간을 지향합니다.

**서비스 바로가기:** https://mklhw0722-cpu.github.io/dongguk-e-eum/

## 주요 기능

### 1. 회원가입 및 관리자 승인 시스템

- Firebase Authentication 기반 회원가입 및 로그인
- 관리자 승인 후 서비스 이용이 가능한 폐쇄형 회원제
- 비로그인·승인 대기·승인 완료 사용자별 접근 제어
- 재학생·졸업생·교수·관리자 역할 구분
- 관리자 전용 회원 승인·거절·권한 관리
- Firestore Security Rules를 활용한 데이터 접근 제어

현재 기본적인 회원 승인 시스템은 구현했으며, 실제 교육학과 소속을 검증하는 절차는 추가 보완할 예정입니다.

### 2. 실시간 채팅 시스템

- 재학생·졸업생·교수 간 1:1 채팅
- 여러 사용자가 참여하는 단체 채팅방
- 채팅방 생성·초대·나가기
- Firestore 기반 실시간 메시지 동기화
- 메시지 읽음 표시 및 읽지 않은 인원 수 표시
- 채팅방 참여자별 접근 권한 관리

향후 신고·차단 등 이용자 보호 기능을 보완할 예정입니다.

### 3. 학교·학과 공지사항

- 학교 공지 및 교육학과 공지
- 학사 일정
- 장학 및 지원 안내
- 교직 관련 안내
- 공지 분류 및 검색
- 공식 공지 연동을 위한 데이터 구조와 동기화 스크립트

공식 홈페이지와의 자동 연동 및 실제 데이터 최신성은 지속적으로 검증하고 있습니다.

### 4. 진로·복수전공 공유방

- 교직·교육행정·기업 HRD·대학원 진학 등 진로별 공유 공간
- 복수전공별 정보 공유
- 질문 및 답변
- 수강 후기 및 진로 경험 공유
- 관심 분야별 정보 탐색

학과 구성원들이 공유한 경험이 일회성 대화로 사라지지 않고 지속적으로 축적되는 것을 목표로 합니다.

### 5. 졸업생 동문 연결

- 졸업생 프로필 탐색
- 진로 분야 및 복수전공별 검색
- 재학생과 졸업생 간 대화
- 멘토링 신청 및 연결을 위한 기능

향후 실제 졸업생 참여 확대와 멘토링 운영 기능을 고도화할 예정입니다.

### 6. 졸업요건 자가점검

- 개인별 입학 연도 및 이수 조건 관리
- 전공·교양·교직 관련 학점 관리
- 이수 강좌 기록
- 교육봉사 시간 및 교직 관련 체크리스트
- 공통 졸업요건과 개인별 이수 기록 구분
- Firestore 기반 개인별 졸업요건 데이터 구조
- 공식 학업이수 가이드 연계

개인별 데이터 자동 저장과 재로그인 후 복원, 공식 졸업요건 기준의 정확성은 계속 검증하고 있습니다.

본 기능은 학생의 졸업 준비를 지원하는 자가점검 도구이며, 학교의 공식 졸업 판정을 대체하지 않습니다.

### 7. 관리자 센터

- 가입 신청 및 승인 상태 관리
- 회원 역할 및 이용 권한 관리
- 공지사항 관리
- 회원 이용 정지 등 관리 기능
- 관리자 권한에 따른 접근 제한

## 실행 방법

Node.js와 npm이 설치된 환경에서 다음 명령어를 실행합니다.

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 에 접속합니다.

Firebase를 사용하는 기능은 별도의 Firebase 프로젝트 설정이 필요합니다.

## 테스트 및 빌드

```bash
npm run typecheck
npm run build
npm test
```

공식 공지 동기화 스크립트:

```bash
npm run sync:notices
```

공지 동기화는 필요한 환경 설정과 외부 사이트 접근 조건을 확인한 후 실행해야 합니다.

## 보안 및 개인정보 보호

동국e음은 교육학과 구성원만 이용할 수 있는 폐쇄형 플랫폼을 지향합니다.

- 관리자 승인 여부에 따른 접근 제어
- 역할별 데이터 접근 권한 구분
- 채팅방 참여자별 메시지 접근 제한
- 개인별 졸업요건 데이터 보호
- Firestore Security Rules 활용
- 개인정보 최소 수집 원칙

실제 운영 전에는 소속 인증, 보안 규칙, 개인정보 처리 및 탈퇴·삭제 절차를 추가로 검증할 예정입니다.

## 프로젝트 안내

동국e음은 동국대학교 교육학과 학생들이 개발하는 비공식 프로젝트이며, 동국대학교에서 공식적으로 운영하는 서비스가 아닙니다.

현재 개발 및 기능 개선이 진행 중이므로 일부 기능은 시범 운영 또는 추가 검증 단계에 있습니다.
